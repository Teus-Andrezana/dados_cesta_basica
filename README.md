# Escopo do Trabalho
O segundo trabalho será uma exploração de dados com foco em extensão utilizando dados de preço de itens de cestas-básicas. Algumas ideias de exploração:

- Previsão de preços futuros (segmentado por mercado, ou geral);
- Previsão de preços de um produto com base em outros produtos;
- Previsão de preços entre mercados (e.g. um mercado precede um aumento de preços?);
- Atraso de mudança de preço comparando mercados contra o preço do produtor;
- Não se limitem às ideias acima, são apenas sugestões para aguçar a criatividade de vocês; o importante é que façam uso das ferramentas aprendidas neste semestre (séries temporais, manipulação de dados, aprendizado supervisionado, etc.), e usem esses problemas reais  como motivação para estudar e aprender outros modelos.

Sendo um trabalho de extensão, a nota desse trabalho será atribuída à atividade de extensão, sendo nota menor que 5 insuficiente.

Avaliação:

    Definir ao menos 2 questões (5pts cada) cada questão deve conter:

    - Questão: o que está sendo estudado nos dados;

    - Objetivo e Motivação: qual conhecimento é esperado ao responder a questão; esse objetivo tem uma aplicação direta ou esperada?

    - Método: como irão explorar tal questão? Quais algoritmos serão usados para explorar o problema e quais métodos de avaliação serão utilizados para avaliar se foi respondida adequadamente;

    - Conclusão: como os dados e modelos obtidos respondem a questão, os objetivos foram atingidos? 

    - Discussão.

A pontuação será dada em arguição conforme justificativas metodológicas e rigor nos processos (parametrização, escolha de algoritmo, manipulação dos dados, avaliação, etc.).

Devem ser submetidos:

- Relatório de extensão INDIVIDUAL, de todos os integrantes;
- Relatório discutindo as questões, com gráficos, tabelas e qualquer estrutura de suporte à discussão que forem necessários;
- Código fonte e demais bases de dados utilizadas no trabalho.

Então cada aluno do grupo deve submeter seu relatório e os arquivos de suporte na atividade de EXTENSÃO, para validação das horas.
